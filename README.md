# Nexus

**Nexus, le launcher de tous tes launchers.**
Steam, Epic, Riot, Battle.net, Xbox… tous tes jeux et tes logiciels au même endroit.

## Installer

1. Télécharge **[Nexus-Setup.exe](https://github.com/Jesuislechef/nexus-releases/releases/latest/download/Nexus-Setup.exe)**.
2. Lance-le. Si Windows affiche « Windows a protégé votre ordinateur » : clique sur
   **Informations complémentaires**, puis **Exécuter quand même** (le programme n'est pas signé,
   c'est normal pour un petit logiciel perso).
3. Clique sur **Installer**.

Ce que l'installation fait sur ton PC, et rien d'autre :
- copie Nexus dans `%LOCALAPPDATA%\Programs\Nexus` (pas besoin d'être administrateur) ;
- crée un raccourci dans le menu Démarrer (et sur le Bureau si la case est cochée) ;
- l'inscrit dans Paramètres > Applications, pour pouvoir le désinstaller normalement ;
- le lance au démarrage de Windows **seulement** si tu coches la case.

## Mises à jour

Nexus te prévient tout seul quand une nouvelle version sort (ou ⚙ > Rechercher une mise à jour).
Tes réglages et tes jeux sont gardés.

Ce dépôt ne contient que le programme d'installation, pas le code source.
